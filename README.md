# wndff.de

Static personal landing page for David and Eva Wendorff, built with Astro and TypeScript.

## Development

```sh
npm ci
npm run dev
npm run verify
```

Portrait preparation, release checks, GitHub Pages deployment, and DNS are documented in [OPERATIONS.md](./OPERATIONS.md).
